# SkillMind LMS

Frontend онлайн-платформы обучения SkillMind.

## Технологии

- React 19 + TypeScript + Vite
- React Router
- Supabase — будет подключён на следующем этапе

## Локальный запуск

```bash
# Установка зависимостей (при первом запуске)
npm install

# Запуск сервера разработки
npm run dev
```

> **Для Windows PowerShell:** если система блокирует выполнение `.ps1` скриптов, используйте команду `npm.cmd run dev`.

Приложение будет доступно в браузере по адресу: **http://localhost:5173/**.

## Проверка сборки и качества кода

```bash
# Проверка типов TypeScript и production-сборка
npm run build

# Проверка качества кода (oxlint)
npm run lint

# Локальный предпросмотр production-бандла
npm run preview
```

## Supabase

Миграции базы данных находятся в папке `supabase/migrations/`:
- `20260916123000_initial_schema.sql` — схема таблиц LMS (курсы, модули, уроки, тесты, задания, сертификаты, аналитика);
- `20260916124000_access_control.sql` — роли пользователей, RLS-политики доступа и Storage-бакеты.

Для подключения к облачной базе заполните переменные в `.env` (скопировав из `.env.example`):
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

## Развёртывание на Vercel

1. Загрузите код в репозиторий GitHub.
2. В панели Vercel выберите **Add New Project** → импортируйте репозиторий **SkillMind**.
3. Добавьте переменные окружения `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`.
4. В проекте уже настроен `vercel.json` с правилами перенаправления (rewrites) для поддержки клиентской маршрутизации React Router.

## Текущий статус

- Интерфейс полностью модульный: каталог с поиском и фильтрами, детальная страница курса с интерактивной программой, интерактивная комната обучения с переключением уроков, личный кабинет студента, кабинет преподавателя с проверкой заданий и аналитикой (экспорт в CSV), панель администратора с модерацией курсов и страница официального сертификата с функцией печати/PDF.

- Клиент Supabase сконфигурирован в `src/lib/supabase.ts` и готов к связыванию с облачной базой.
